演示控制台

点击按钮模拟三种刷新场景。注意观察：刷新过程中顶栏与左侧菜单完全不动，只有右侧内容区出现反馈。

1刷新范围：仅内容区

顶栏与侧边栏在路由切换、自动刷新、手动刷新时均保持静态，不重新渲染、不闪烁。加载反馈只出现在 main 内容区内。

2有数据刷新 = 不打断

已有数据的页面刷新时：内容区顶部出现 2px 蓝色渐变进度条，内容轻微透明（55%）且不可点，刷新按钮图标旋转。数据到达后就地更新，不清空、不闪白。

3无数据首载 = 骨架屏

首次进入或数据为空时展示骨架屏（微光扫过动画），轮廓与真实表格一致，避免突兀的全屏菊花图。统一废弃各页面散落的 Spin 文案。
