# 统一页面刷新机制方案

> 版本：v1.0 ｜ 日期：2026-08-09 ｜ 状态：已实施
>
> 配套设计稿：[页面刷新交互设计稿.html](./页面刷新交互设计稿.html)（含可点击的交互演示）

## 1. 现状问题

1. **加载样式不统一**：各页面自行使用 Ant Design `Spin`，提示文案各异——"加载中…"（PageContainer）、"正在加载需求详情…"、"正在加载编辑数据…"、"正在加载系统…"、"正在加载版本…"等，视觉与文案均无规范。
2. **刷新体验打断**：刷新时整块内容被菊花图遮罩替换，数据先消失再出现，产生"闪白"，用户无法在刷新期间阅读现有数据。
3. **刷新范围过大**：部分场景下顶栏与侧边栏随内容区一起出现加载反馈，左侧固定的模块导航不应参与任何刷新。

## 2. 设计原则

- **固定区域零刷新**：顶栏（topbar）与侧边栏（sidebar）为应用级框架，路由切换、自动刷新、手动刷新时均保持静态——不重新渲染、不请求、不出现加载态。
- **刷新反馈只发生在 `main` 内容区**。
- **有数据刷新不打断阅读**：保留现有数据，仅给出轻量加载信号。
- **无数据首载给轮廓**：用骨架屏替代全屏菊花图。
- **统一文案与组件**：全站一套规范，废弃散落各处的自定义 tip。

## 3. 刷新场景与对应形态

| 场景 | 触发 | 加载形态 |
|---|---|---|
| ① 数据刷新（已有数据） | 手动点刷新按钮、`refreshBus` 自动刷新、keep-alive 页面重新激活 | 内容区顶部 2px 蓝色渐变进度条（循环滑动）+ 内容透明度降至 55% 且禁止点击 + 刷新按钮图标旋转 |
| ② 首次进入（无数据） | 路由进入、页面尚无缓存数据 | 骨架屏（与真实内容等形的灰色块，微光扫过动画） |
| ③ 加载完成 | 数据返回 | 进度条淡出、内容恢复不透明、就地更新数据，页头"更新于 HH:mm:ss"时间戳同步刷新 |
| ④ 加载失败 | 接口异常 | 保留旧数据，右上角统一 `message.error('数据刷新失败，请稍后重试')`，不打断当前页面 |

## 4. 视觉规范（与设计稿一致）

- **进度条**：高 2px，贴内容区上沿（`position: sticky; top: 60px`），蓝色渐变 `#1677ff → #69b1ff`，1.1s 循环滑动动画，结束时淡出。
- **内容降透明**：`opacity: .55; pointer-events: none; transition: .25s`——明确表示"正在更新"，同时保留可读性。
- **刷新按钮**：页头操作区固定位置的 34×34 方形图标按钮（⟳），加载中图标 0.8s 线性旋转、边框变主色；旁置"更新于 HH:mm:ss"时间戳。
- **骨架屏**：圆角灰块 `#f2f4f7 / #e8ecf1` 渐变微光（1.4s），行列尺寸与真实表格一致。

## 5. 前端实现方案

### 5.1 布局隔离（保证侧边栏不刷新）

- `App.vue` 中顶栏 + 侧边栏位于 `<router-view>` 之外，本身不随路由重渲染；需确认侧边栏的激活态仅由路由 `meta` 驱动，不发起数据请求。
- 所有加载态组件一律挂载在页面内容组件内部，禁止在 `App.vue` 根节点包全局 `Spin`（当前初始化用的全屏 `Spin` 仅限首次登录鉴权，保留）。

### 5.2 统一组件

新增两个基础组件，替换各页面散落的 `Spin`：

```
components/
  PageRefreshBar.vue   # 2px 顶部进度条，props: active
  ContentSkeleton.vue  # 骨架屏，props: rows / 形态预设（table / card / form）
```

### 5.3 usePageRefresh 改造

`usePageRefresh` 增加状态输出，供页面统一绑定：

```ts
const { refresh, refreshing, loaded } = usePageRefresh('systems', loadSystems)
// refreshing: 有数据的后台刷新中 → 驱动进度条 + 内容降透明
// !loaded:    尚无数据 → 驱动骨架屏
```

页面模板统一模式：

```vue
<PageRefreshBar :active="refreshing" />
<div class="page-content" :class="{ 'is-refreshing': refreshing }">
  <ContentSkeleton v-if="!loaded" preset="table" :rows="5" />
  <template v-else> …真实内容… </template>
</div>
```

### 5.4 手动刷新入口

各列表/详情页页头固定放置刷新按钮 + "更新于"时间戳；点击调用 `refresh()`，加载中图标旋转。按钮与时间戳样式按设计稿实现。

### 5.5 替换清单（现状 → 目标）

| 位置 | 现状 | 目标 |
|---|---|---|
| PageContainer.vue | `Spin tip="加载中…"` | 骨架屏 / 进度条 |
| RequirementDetail.vue | `Spin tip="正在加载需求详情…"` | 骨架屏（详情形态） |
| RequirementEditor.vue | `Spin tip="正在加载编辑数据…"` | 骨架屏（表单形态） |
| SystemManagement.vue | 两个 `Spin`（系统/版本） | 骨架屏 + 进度条 |
| 其余页面 | 各处 `loading` 表格态 | 统一接入上述组件 |

## 6. 验收标准

1. 切换菜单时侧边栏无任何闪烁、无网络请求。
2. 任意页面点击刷新：进度条出现、旧数据保持可见，数据返回后就地更新。
3. 全站不再出现自定义 `Spin` 文案；加载失败提示统一为一条 error 消息。
4. 骨架屏轮廓与真实内容行列对齐，无布局跳动。
