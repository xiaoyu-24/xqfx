# 需求收集平台分角色操作手册

## 1. 使用范围与字段标识

本系统当前没有登录和权限隔离。本手册中的“需求填报人”“需求处理人”“系统管理员”表示业务职责，不限制人员访问现有菜单。

- 红色“* 必填”：正式提交或保存时必须填写。
- 灰色“选填”：可根据实际情况填写。
- 条件必填：仅在选择特定业务条件后变为必填，例如选择“新系统”后的系统名称和负责人。
- 查询区域统一显示“筛选条件均为选填”。
- 草稿允许必填内容暂未完成；草稿转正式需求时必须补充完整。

### 1.1 页面导航与数据刷新

系统使用 Ant Design Vue 的侧栏工作台。通过左侧菜单在“填写需求”“需求列表”“管理需求”“系统管理”和版本管理之间切换。

- 进入页面或切换回已打开的页面时，系统会自动加载最新业务数据。
- 新增、修改、删除、上传附件或保存处理情况成功后，受影响的列表会自动刷新。
- 页面没有手动刷新按钮，也不会显示“最后更新时间”。
- Word、Excel 附件转换预览期间，系统会自动检查生成状态；这是附件预览任务的状态更新，不需要用户手动刷新业务列表。

## 2. 需求填报人

### 2.1 新建和暂存需求

1. 进入“填写需求”。
2. 按字段标识填写姓名、需求标题、类型和需求内容。
3. 在“部门”下拉框中选择一个部门：IT部、FAE部、总经办、供应链部、财务部、产品部、市场运营部、业务部、品质部或人力资源部；不能手工输入其他部门。
4. 需求时间周期为选填；填写时开始和结束日期必须同时选择，且结束日期不得早于开始日期。
5. 所属系统可选择已有系统、新系统或暂无系统。
6. 选择已有系统时必须选择系统，目标版本为选填。
7. 选择新系统时必须填写系统名称和负责人，协助人为选填，多人使用逗号分隔。
8. 信息未完成时点击“暂存”；信息完整后点击“保存需求”。正式需求初始状态为“待评估”。
9. 离开未保存的填写页时，根据系统提示选择继续编辑或放弃修改。

### 2.2 上传和预览附件

附件为选填，支持JPG/JPEG、PNG、GIF、WEBP、PDF、DOC/DOCX、XLS/XLSX，单个文件最大100MB。

1. 在填写页或编辑需求时，可点击附件上传区选择文件，也可将文件直接拖入上传区。
2. 图片和PDF上传后可直接点击“预览”。
3. Word和Excel上传后由服务器转换为PDF；列表会显示“等待生成预览”或“正在生成预览”。
4. 转换完成后“预览”按钮自动出现，无需重新打开详情。
5. 转换失败时可查看失败原因并点击“重新生成”。
6. 预览失败不代表原文件丢失，始终可以点击“下载原文件”。
7. Office在线预览可能与原文件存在轻微版式差异，正式内容以下载的原文件为准。
8. 不支持的格式、超过100MB的文件不会加入待上传列表；重复选择同一文件时系统会自动去重。

### 2.3 查询和编辑需求

1. 进入“需求列表”，或从其他页面切换回该页时，系统会自动加载最新需求。
2. 可组合系统、版本、部门、填写人、填写时间、类型、状态、保存类型、关键词和周期范围筛选。
3. 点击“查看详情”查看完整内容、附件和处理结果。
4. 点击“编辑”修改需求；草稿可以继续暂存或正式提交。
5. 点击“删除”后再次确认。若提示记录已被其他人修改，可切换到其他页面后再返回，或重新打开该页后重试。

## 3. 需求处理人

1. 进入“管理需求”，查看草稿和状态为待评估、已确认、开发中或暂停的正式需求。
2. 打开目标需求，核对内容、所属系统、目标版本、周期和附件。
3. 点击附件“预览”快速查看；预览不可用时下载原文件。
4. 点击“填写处理情况”，系统会打开处理情况弹窗。
5. 在弹窗内填写处理信息。需求状态为必填，可选择待评估、已确认、开发中、暂停、已完成、已拒绝或已关闭。
6. 完成时间、处理人和完成情况为选填，按实际情况填写；点击“取消”或关闭弹窗不会保存修改。
7. 点击“保存处理情况”。保存成功后弹窗关闭，管理需求和需求列表会自动刷新；出现并发修改提示时重新打开该页后重试。
8. 已完成、已关闭或已拒绝的需求会移出“管理需求”，但仍可在“需求列表”查询。

## 4. 系统管理员

### 4.1 系统和版本维护

1. 进入“系统管理”。筛选条件均为选填。
2. 新增或编辑系统时，系统名称和负责人必填，协助人选填。
3. 根据业务情况启用或停用系统。
4. 进入版本管理，新增或编辑版本名称，并按需要启用或停用版本。
5. 删除有关联需求的系统前，先把需求迁移到其他启用系统或暂无系统。
6. 有关联需求的版本不能删除。

### 4.2 附件预览运维

1. 定期检查原始附件目录和预览目录剩余空间。
2. 检查LibreOffice可执行文件是否可运行，以及服务账号是否有预览目录写权限。
3. 查看后端日志中的转换超时、失败、队列拒绝和文件清理错误。
4. 对偶发失败附件执行“重新生成”；连续失败时下载原文件确认是否损坏。
5. 备份数据库和原始附件目录。预览目录是可重建缓存，可不纳入日常备份。
6. 恢复或迁移后抽查图片、PDF、Word和Excel预览以及原文件下载。

## 5. 常见问题

| 问题 | 处理方法 |
|---|---|
| 草稿为什么可以缺少必填项 | 暂存用于保存未完成内容，正式提交时才执行完整校验 |
| Word或Excel预览为什么需要等待 | 服务器正在通过LibreOffice转换为PDF |
| 预览与原文件版式不一致 | 在线预览用于快速查看，请下载原文件确认正式版式 |
| 预览失败是否影响下载 | 不影响，原文件与预览缓存分开保存 |
| 为什么不能手工填写部门 | 为统一统计口径，部门只能从系统提供的十个规范部门中选择 |
| 为什么没有手动刷新按钮或“最后更新时间” | 页面切换和内容修改成功后会自动刷新相关数据；Office预览状态也会自动更新 |
| 系统或版本无法删除 | 存在关联需求，需要先迁移或解除关联 |
| 保存提示已被其他人修改 | 刷新记录并重新操作，避免覆盖他人修改 |
