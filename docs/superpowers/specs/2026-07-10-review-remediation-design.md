# 需求收集平台审查问题修复设计

## 1. 目标与范围

本设计用于修复 2026-07-10 全面审查中发现的全部高、中优先级问题。采用方案 A：保留现有 Vue、Spring Boot、MySQL 和 API 主体结构，针对数据一致性、核心操作闭环、附件可靠性、错误处理、索引和自动化验证进行修复，不引入登录权限或无关功能。

## 2. 数据一致性

### 2.1 软删除记录不可再引用

需求创建、草稿更新、正式编辑和版本管理统一使用 `deleted = false` 的仓库查询。已删除系统或版本的接口返回 404；停用系统、版本只能由原来已经关联它们的历史需求继续保留，不能主动新建关联。

系统版本的列表接口先确认系统未删除；不存在或已删除系统返回 404，不再返回误导性的空列表。

### 2.2 系统版本名称唯一

`system_versions` 增加可为空的 `active_name_key`。未删除版本保存 `trim + lowercase` 后的名称，同一系统通过 `(system_id, active_name_key)` 唯一约束防止重名；软删除时将该字段清空，从而允许以后重新创建同名版本。

服务层在新增和改名时提前返回 409，数据库唯一约束作为并发兜底。若历史数据库已经存在重复版本，迁移应明确失败并要求先清理数据，不自动改名。

### 2.3 并发控制

需求状态更新和系统启停请求增加 `recordVersion`，与普通编辑使用同一乐观锁规则。前端发送当前版本，冲突统一返回 409。

批量迁移需求时同时执行 `recordVersion = recordVersion + 1`，使迁移前打开的旧编辑页面失效，避免旧页面覆盖迁移结果。

## 3. 前端核心流程

### 3.1 草稿正式提交

草稿编辑区提供两个明确动作：保存草稿、正式提交。保存草稿继续调用 `/requirements/{id}/draft`；正式提交调用 `/requirements/{id}`，执行正式字段校验并生成待评估状态。

### 3.2 状态回退

“待评估”的值修正为 `PENDING_EVALUATION`，确保任何正式需求都可明确改回待评估。

### 3.3 附件补传

详情页增加附件选择和上传按钮，可在需求保存后继续补传。新建页多文件上传按文件逐个移除成功项；失败项保留，提示中明确需求已保存并可在详情补传。

图片预览增加最大宽高和 `object-fit`，避免大图撑开页面。

## 4. 附件安全与存储

上传仍保持流式写入临时文件并计算 SHA-256。文件写完后按真实文件签名检查：图片、PDF 使用固定文件头，DOC/XLS 使用 OLE 文件头，DOCX/XLSX 检查 ZIP 内的 `word/` 或 `xl/` 目录。客户端 MIME 只作为辅助信息，不再作为唯一依据。

原子移动不可用时降级为普通同目录移动。附件删除同时清理实体文件；若文件已经丢失，仍允许清理数据库记录。

下载响应使用 Spring `ContentDisposition` 构建 UTF-8 文件名，避免中文和特殊字符破坏响应头。

## 5. 错误处理与日志

统一处理参数校验、数据库约束、乐观锁、业务状态和未知异常。响应至少包含 `message`；未知异常额外包含 `traceId`，服务端日志记录同一编号和堆栈，不记录数据库密码或文件内容。

数据库唯一约束冲突返回 409，不向前端泄露 SQL 和表结构。

## 6. 数据库索引

新增需求填写时间、周期、类型、状态、保存类型与删除标记的组合索引，并为附件的 `requirement_id, deleted` 增加索引。保留现有系统和版本关联索引。

## 7. 自动化验证

所有行为变更严格按 TDD 执行：

1. 后端 API 测试覆盖已删除实体、版本重名、状态乐观锁、迁移版本递增、统一错误和附件真实格式。
2. 前端组件测试覆盖草稿正式提交、待评估回退、附件补传、失败项保留和图片尺寸样式。
3. 增加可在 Docker 可用时运行的 MySQL Testcontainers 集成测试，验证 Flyway、唯一约束和应用上下文。
4. 最终运行后端全量测试、前端全量测试和构建、真实 MySQL 空库启动、关键浏览器流程与 `git diff --check`。

## 8. 完成标准

- 全面审查列出的高、中优先级问题均有对应代码修复和自动化测试。
- 所有自动化测试通过，真实 MySQL 的 V1 至最新迁移成功。
- 草稿可正式提交，已删除系统/版本不可引用，版本名称唯一，附件可补传。
- 并发状态更新和系统迁移不会静默覆盖其他修改。
- 未知错误可通过追踪编号定位，数据库筛选索引与附件索引已创建。
- 工作区干净，修复按已验证的小批次提交。
