# 需求收集平台使用手册

## 菜单

- **填写需求**：新建正式需求或暂存草稿。
- **需求列表**：组合筛选、查看详情、编辑和删除需求。
- **系统管理**：维护系统、负责人、协助人和版本。

## 填写需求

正式保存时必须填写姓名、部门、标题、类型（BUG 或需求）和需求内容。需求时间周期可不填；填写时开始和结束日期必须同时选择，且结束日期不得早于开始日期，日期按上海时间解释。

所属系统可选择已有系统、**新系统**或**暂无系统**。选择新系统时必须填写系统名称和负责人，协助人可用逗号分隔。选择已有系统后可选目标版本；更换系统会清空原版本。

“暂存”允许字段不完整，可在需求列表按“保存类型：草稿”找到并继续编辑。正式保存的需求默认状态为“待评估”。离开未保存的填写页会出现确认提示。

附件支持 JPG/JPEG、PNG、GIF、WEBP、PDF、DOC/DOCX、XLS/XLSX。上传完成后会绑定到需求；图片可在需求详情中预览，其余文件可下载。

## 查询和处理需求

在“需求列表”中可组合系统、版本、部门、填写人、填写时间、类型、状态、保存类型、关键词和周期范围进行筛选。周期范围会匹配与筛选区间有重叠的需求。

“查看详情”显示完整内容和附件；“编辑”可修改字段和需求状态；“删除”会再次确认，删除后不再出现在列表中。若其他页面已修改同一条需求，保存会提示刷新后重试。

状态包括：待评估、已确认、开发中、暂停、已完成、已拒绝、已关闭。

## 系统与版本管理

每个系统必须有一名负责人，可维护多名协助人。系统及版本可启用或停用；停用后不能用于新需求，但历史需求保持可查看。

有未删除关联需求的系统不能直接删除。先使用迁移功能将需求移到另一个启用系统或“暂无系统”，再删除系统。版本同样只有在无关联需求时才可删除。
