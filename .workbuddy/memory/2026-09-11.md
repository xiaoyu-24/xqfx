## 附件上传报"附件内容与文件格式不匹配"排查
- 报错来源：backend/src/main/java/com/xqfx/requirements/requirement/AttachmentService.java:47 的魔数校验 hasValidFileSignature（jpg 要求文件头 FF D8 FF）。
- 前端 FormData 原样上传无转码；扩展名与 Content-Type 校验已通过（否则报"不支持的附件格式"），故根因是文件内容不是真 JPEG（典型：WebP/PNG 改名 .jpg，常见于微信保存图）。
- 结论：校验逻辑按设计工作，文件本身扩展名与实际格式不符。
- 更正：本项目后端实际为 Java Spring Boot（backend/，端口 8080），此前记忆中的 FastAPI 有误。
